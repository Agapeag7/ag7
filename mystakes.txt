🧩 Fonctionnalités à ajouter côté backend (PHP)
Dans ag.class.php, il faut enrichir la classe Router avec les méthodes suivantes :

1. actionCreateStory()
Vérifier l’authentification.

Récupérer story_text (optionnel) et story_type (déduit de la présence d’une image).

Gérer l’upload d’une image (réutiliser Utils::uploadPostImage ou créer une méthode dédiée dans Utils).

Insérer dans la table stories avec une date d’expiration (+24h par défaut).

Retourner l’ID de la story créée.

2. actionGetActiveStories()
Récupérer toutes les stories non expirées (getActiveStories() du modèle).

Regrouper par utilisateur pour l’affichage du feed (optionnel, mais pratique).

Ajouter les informations sur le nombre de vues et si l’utilisateur courant a déjà vu la story (via StoryViewsModel).

3. actionGetUserStories($user_id)
Récupérer les stories actives d’un utilisateur spécifique (pour son propre profil ou en cas de clic).

4. actionViewStory()
Enregistrer une vue pour une story (StoryViewsModel::addView()). Appelée automatiquement à l’ouverture de la story.

5. actionDeleteStory() (optionnel)
Permettre à l’utilisateur de supprimer sa propre story avant expiration.

⚠️ Note de sécurité : toutes ces actions doivent vérifier $_SESSION['user_id'].

private function actionCreateStory() {
    if (!isset($_SESSION['user_id'])) {
        Utils::jsonResponse(['success' => false, 'message' => 'Non authentifié'], 401);
    }

    $text = $_POST['story_text'] ?? '';
    $hasImage = isset($_FILES['story_image']) && $_FILES['story_image']['error'] === UPLOAD_ERR_OK;

    if (empty($text) && !$hasImage) {
        Utils::jsonResponse(['success' => false, 'message' => 'Aucun contenu'], 400);
    }

    $type = $hasImage ? 'text-image' : 'text';
    $imageUrl = null;

    if ($hasImage) {
        // Réutiliser la fonction d'upload des posts ou créer une version pour stories
        $imageUrl = Utils::uploadPostImage($_FILES['story_image']['tmp_name'], $_FILES['story_image']['name']);
        if (!$imageUrl) {
            Utils::jsonResponse(['success' => false, 'message' => 'Échec de l\'upload'], 500);
        }
    }

    $storyModel = new StoryModel($this->db);
    $storyId = $storyModel->create([
        'story_user_id' => $_SESSION['user_id'],
        'story_type' => $type,
        'story_text' => $text,
        'story_image_url' => $imageUrl,
        'story_duration' => 24
    ]);

    Utils::jsonResponse(['success' => true, 'story_id' => $storyId]);
}

private function actionGetActiveStories() {
    $storyModel = new StoryModel($this->db);
    $stories = $storyModel->getActiveStories(100);
    $viewModel = new StoryViewsModel($this->db);
    $currentUserId = $_SESSION['user_id'] ?? null;

    $result = [];
    foreach ($stories as $story) {
        // Ajouter le compte de vues réel
        $story['viewers_count'] = $viewModel->getViewCount($story['story_id']);
        if ($currentUserId) {
            $story['viewed'] = $viewModel->hasViewed($story['story_id'], $currentUserId);
        }
        $result[] = $story;
    }

    Utils::jsonResponse(['success' => true, 'stories' => $result]);
}

async function renderStories() {
    const container = document.getElementById('storiesContainer');
    container.innerHTML = ''; // Bouton "Votre story" reste géré manuellement

    const result = await StoriesAPI.getActiveStories();
    if (!result.success) return;

    // Regrouper par utilisateur
    const storiesByUser = {};
    result.stories.forEach(story => {
        if (!storiesByUser[story.story_user_id]) storiesByUser[story.story_user_id] = [];
        storiesByUser[story.story_user_id].push(story);
    });

    // Créer un élément par utilisateur avec son avatar
    for (const userId in storiesByUser) {
        const userStories = storiesByUser[userId];
        const firstStory = userStories[0];
        const storyEl = document.createElement('div');
        storyEl.className = 'story-item';
        storyEl.innerHTML = `
            <div class="story-avatar" style="background-image: url('${firstStory.user_photo_url ? 'imgApp/'+firstStory.user_photo_url : ''}');"></div>
            <span class="story-name">${firstStory.user_name}</span>
        `;
        storyEl.addEventListener('click', () => openStoryCarousel(userStories));
        container.appendChild(storyEl);
    }
}
