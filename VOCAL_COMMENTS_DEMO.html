Guide rapide d'utilisation et démonstration des commentaires vocaux

🎯 Qu'est-ce que les commentaires vocaux ?

Les commentaires vocaux permettent aux utilisateurs d'enregistrer et partager des messages audio directement en réaction à un post.

  • Enregistrement audio via microphone
  • Aperçu avant envoi
  • Stockage sécurisé sur serveur
  • Lecteur intégré dans l'interface
  • Support anonyme
  • Like et suppression comme commentaires texte
  • Réponses vocales possibles
    • 💡 Astuce:

    Parfait pour partager des avis rapidement sans taper, envoyer des réactions vocales, ou pour l'accessibilité.

    📖 Comment utiliser

    Pour enregistrer un commentaire vocal:

    1. Ouvrir le modal de commentaires sur un post 2. Cliquer l'onglet "🎙️ Vocal" 3. Cliquer "Commencer" 4. Accorder l'accès au microphone (pop-up navigateur) 5. Enregistrer votre message 6. Cliquer "Arrêter" 7. Écouter l'aperçu 8. Options: "Réenregistrer" ou "Poster" 9. Cliquer "Poster" pour envoyer

    Pour écouter un commentaire vocal:

    Les commentaires vocaux s'affichent avec un lecteur audio. Cliquer sur "Play" pour écouter.

    🖥️ Interface

    Modal avec onglets Texte/Vocal:

    Le modal de commentaires affiche deux onglets permettant de basculer entre commentaires texte et vocaux.

    📝 ONGLET TEXTE (DÉFAUT)

    Contient:

    • Input texte pour écrire
    • Bouton "Poster"
    • Checkbox "Anonyme"

    🎙️ ONGLET VOCAL

    Contient:

    • Bouton "Commencer"
    • Timer visible lors enregistrement
    • Aperçu audio après arrêt
    • Boutons "Poster" et "Réenregistrer"

    Affichage des commentaires vocaux:

    Exemple de commentaire vocal:

    User123 🎙️ Vocal • 14:30
    [Lecteur audio avec contrôles de lecture]
    ⏱️ Durée: 0:45

    Formats audio supportés:

    Enregistrement: WAV (standard)
    Acceptés: MP3, WAV, OGG, WebM, M4A

    ⚠️ Note: Nous utilisons WAV pour l'enregistrement car c'est nativement supporté par tous les navigateurs via MediaRecorder API.

    🔌 Utilisation API

    Envoyer un commentaire vocal:

    const result = await ActusAPI.addVocalComment( postId, // ID du post (number) audioFile, // File object (File) duration, // Durée en secondes (number) parentId, // Optionnel: ID du commentaire parent isAnonymous // Optionnel: booléen ); if (result.success) { console.log('✅ Commentaire vocal posté!'); console.log(result.comment); // Affiche les données du commentaire }

    Récupérer les commentaires (avec audio):

    const result = await ActusAPI.getComments(postId); result.comments.forEach(comment => { if (comment.audio_url) { console.log('Commentaire vocal:', comment.audio_url); } else { console.log('Commentaire texte:', comment.text); } });

    🔧 Dépannage

    ❌ "Accès microphone refusé"

    1. Vérifier les permissions navigateur pour le microphone
    2. Autoriser le site pour accéder au microphone
    3. Sur Safari, utiliser HTTPS
    4. Redémarrer le navigateur si nécessaire

    ❌ "Fichier audio non trouvé"

    1. Vérifier que le répertoire audio/comments/ existe
    2. Vérifier les permissions (chmod 0777)
    3. Vérifier l'espace disque disponible

    ❌ "Onglets ne changent pas"

    1. Ouvrir la console développeur (F12)
    2. Vérifier l'absence d'erreurs JavaScript
    3. Vérifier que actus-complete.js est chargé

    🚀 Prochaines étapes
